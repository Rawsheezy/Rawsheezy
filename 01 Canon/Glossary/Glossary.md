| Term | Meaning |

| **Spin** | A print volume / chapter. Spin 1 = A New Place, Spin 2 = Discovery. |
| **G.I.M.M.E.** | Gear-Integrated Magnetic Motion Equipment |
| **Emb-IC** | Embedded-Integrated Controller Operating System |
| **M.A.X.W.E.L.L.** | The control loop: Map, Adapt, eXtract, Waveform, Establish, Launch, Look again |
| **G.E.A.R.** | Grand Engineering & Automation Registry (the city's database) |
| **CoG** | City of Gears; **CoG-7** is Alset's section |
| **MLZ** | Magnetic landing zone |
| **MSD** | Shown in Spin 2, pp.37-39 (read as "Material Selection Diagram"; **[verify]**) |
| **Arch-Gavel** | Celise's chained hammer |
| **R.I.S.E.** | Receptor, Integrator, Synapse, Effector: the Substack series |
| **Flux** | How much magnetic field passes through an area, and in which direction |
