# Lettering and Design Standards

## Lettering
- [ ] One balloon font for speech, one for system text, one for captions.
- [ ] Minimum type size tested at ~800 px page width.
- [ ] Every balloon and caption has a tail or a clear speaker cue.
- [ ] No overlapping or clipped balloons.
- [ ] Floating captions get a balloon shape or a clear background over screentone.

## Page checks
- [ ] Reading order is obvious on every page.
- [ ] Establishing panel before action scenes so positions are clear.
- [ ] Flashbacks are marked (border, tone or caption).
- [ ] New characters get a full-figure first appearance and a name label.
- [ ] Each weekly drop ends on a beat.
